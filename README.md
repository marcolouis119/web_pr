# Modal Template

Четвертое задание проекта по вебу

## Описание

"Ваша идеальная прогулка" - это приложение, которое помогает пользователям выбрать маршрут для прогулки, основываясь на их текущем настроении и местоположении. Приложение использует Geolocation API для определения местоположения пользователя и предлагает маршруты, которые соответствуют его эмоциональному состоянию.

## Функциональность

- Определение местоположения пользователя с помощью Geolocation API
- Выбор маршрутов на основе настроения
- Интерактивная карта с основными городами России
- Адаптивный дизайн для различных устройств
