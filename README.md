# Маршруты для прогулок в Санкт-Петербурге

Веб-приложение для выбора маршрутов прогулок в зависимости от настроения.

## Приложение доступно в Dorcel:

https://webpr2-marcolouis119s-projects.vercel.app/

## О проекте

Этот проект помогает пользователям найти интересные места для прогулок в Санкт-Петербурге в зависимости от их текущего настроения. Приложение предлагает маршруты для:
- Расслабления и умиротворения (парки и тихие места)
- Активного отдыха (парки и достопримечательности)
- Развлечений (бары и кафе)

## Функциональность

- Выбор маршрутов по настроению
- Просмотр всех доступных маршрутов на карте
- Построение маршрута от текущего местоположения до выбранного места
- Адаптивный дизайн для разных устройств

## Технологии

- Frontend: React, Leaflet, Leaflet Routing Machine
- Карты: OpenStreetMap
- Маршрутизация: OSRM (Open Source Routing Machine)
- Стили: CSS Modules

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/marcolouis119/web_pr/tree/1.2
web_pr
```
### 2. Установка и запуск

```bash
npm install
npm start
```
